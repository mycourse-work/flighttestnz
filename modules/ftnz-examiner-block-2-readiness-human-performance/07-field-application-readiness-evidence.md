# Field Application — Readiness and Evidence Aid

This extended application lesson turns Block 2 into a repeatable assessment-readiness and human-performance review. Use it when several individually manageable threats are beginning to combine or when a candidate’s performance changes as conditions change.

## Part 1 — make the commencement decision explicit

List the conditions without deciding too early:

| Area | What is known? | What remains uncertain? |
| --- | --- | --- |
| Candidate eligibility and prerequisites | | |
| Documentation and assessment legitimacy | | |
| Examiner readiness, recency and workload | | |
| Aircraft/simulator and equipment | | |
| Weather and operational conditions | | |
| Time, commercial or organisational pressure | | |

Then ask:

1. Is the assessment legitimate to commence?
2. What threats could affect safety, fairness or reliable evidence?
3. Which threats can be managed, by what control, and by whom?
4. What condition would require delay, pause or termination?

Likely competence, travel inconvenience and operator preference do not cure an unverified prerequisite or an unsuitable assessment environment.

## Part 2 — interpret the change, not just the error

When performance changes, record the sequence:

- What behaviour changed?
- What context or workload changed at the same time?
- What information was available to the candidate?
- What did the candidate recognise, and when?
- What action managed or failed to manage the situation?
- Did similar behaviour occur elsewhere?
- Which competency or standard is being sampled?

![Flight examiner reviewing assessment readiness beside an aircraft as weather changes](./assets/assessment-readiness-scene.png)

## Part 3 — test for bias and recovery

Do not let strong early performance create a halo effect. Do not let one poor event create a horn effect. Ask what evidence would change your conclusion, then consider whether the candidate’s recovery is independent, timely and effective.

Recovery is part of the evidence sequence. It is neither an automatic pass nor an eraser of the original event.
